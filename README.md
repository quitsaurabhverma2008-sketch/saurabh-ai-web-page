# Saurabh AI - 3D Animated Website

A powerful, visually stunning promotional website for Saurabh AI featuring 3D animations, real-time API integration, and modern web design.

## Features

### 3D Animations
- Three.js 3D animated background with floating geometric shapes
- Particle system with gradient colored particles
- Loading screen with animated logo
- Pulse rings and orb animations
- 3D tilt effect on cards
- Cursor glow effect
- Parallax scrolling

### Sections
- **Hero** - Stunning animated intro with floating AI orb
- **Features** - 6 key features with hover effects
- **AI Models** - Auto-scrolling carousel of 12 AI models
- **Chat Modes** - 8 specialized chat modes with category tabs
- **Tech Stack** - Technology showcase
- **Live Demo** - Real-time chat connected to Saurabh AI API
- **CTA** - Call to action with animated background

### Live Demo Chat
The demo section is connected to the real Saurabh AI backend API:
- Real-time streaming responses
- Typing indicator
- Chat history
- Identity system (AI introduces itself as Saurabh AI)

## Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript ES6+
- **3D Graphics**: Three.js
- **Styling**: Custom CSS with modern design
- **Backend**: FastAPI (for live demo)
- **API**: Groq API (10 active keys)

## Quick Start

1. **Open in Browser**:
   ```bash
   # Start a local server
   python -m http.server 8000
   # Then visit http://localhost:8000
   ```

2. **For Live Demo** (requires backend):
   ```bash
   # In another terminal, start the backend
   cd saurabh-ai
   python backend/server.py
   ```

3. **View Live**: https://quitsaurabhverma2008-sketch.github.io/saurabh-ai-web-page/

## Files

- `index.html` - Main HTML structure
- `styles.css` - All animations and styles
- `script.js` - Three.js 3D effects and interactions
